# Schoolyard Defence by Daniel Luo

Play the game: https://postup17.github.io/daniel-luo-defence/

A browser-playable Godot tower defence game with Playground, Library, and
School Oval maps, teacher upgrades and special abilities, and Bruce Vader.

This repository contains the exported web game. Saved progress stays in the
current browser and device; switching website addresses starts a separate save.

The editable Godot project is backed up separately in a private repository.
